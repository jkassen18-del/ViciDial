Link sources

Company links come from JSON files your teams publish (one for the whole company, more per department). Sources higher in the list win when two define the same go-link. Links pushed directly by policy always come first.

Address bar

How typing a go-link in the browser's address bar reaches Go-Links.

Short hostThe word before the slash. With “go” you type go/payroll; some companies prefer “to” or “l”. One word, letters, digits and dashes.
http://
Allow the new short hostGo-Links needs permission to redirect this host.
Redirect typed short linksTurns http://go/anything into the right destination before the browser even looks the name up.
Catch go-links sent to a search engineWhen the browser searches for “go/payroll” instead of opening it, jump to the link instead. Works on Google, Bing, DuckDuckGo, Yahoo, Ecosia and Brave Search.
KeywordType go then Space (or Tab) in the address bar for live suggestions. The keyword is fixed by the browser at install time and can’t be changed here; Chrome and Edge let you change it under Settings → Search engine → Manage → Extensions.

Personal links

Shortcuts that only exist in this browser. A personal link can never replace a company link.

Allow personal linksLet people create their own go-links in addition to the company directory.

Behaviour

Open links in a new tabApplies to links picked in the popup and the directory. Ctrl/⌘ + Enter always opens a new tab.
Show featured links in the popupThe “Start here” links your company highlights for new starters.
Rank by what I useCounts how often you open each link to sort suggestions and “Most used”. Counts stay on this device.
Refresh sources everyMinutes between checks for updated links (5 – 1440). Sources are also refreshed when the browser starts.
Directory welcome messageShown under the headline of the directory page. Leave empty for the default.
