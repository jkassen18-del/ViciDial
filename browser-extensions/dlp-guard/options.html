Protection

Where Data Leak Guard looks, and what happens when it finds something sensitive.

Scope

Protect"Everywhere" checks every site except your trusted company domains (recommended). "Listed only" checks just the high-risk list.
Default actionUsed by custom rules and by any detector set to "Default".
On high-risk sitesEscalate warnings on public AI tools, personal e-mail and file sharing. "Log only" rules stay silent.
Require a reason to continueUsers must type a business justification before "Continue anyway". The reason is kept in the incident log.

Channels

PasteText and files pasted into any field or editor.
Drag and dropText and files dropped onto a page.
File uploadsFile pickers: file names are always checked, and the contents of text-like files (txt, csv, json, env, pem, sql…).
Typed messages (send / submit)Checks what was typed when pressing Enter or submitting a form. High-risk sites only. Off by default to avoid noise.

Files

Detectors

Built-in detectors use checksums and format rules (Luhn, mod-97, area numbers…) to keep false alarms low. Choose what each one does.

One per line. Matched as whole words, case-insensitive (e.g. CONFIDENTIAL, INTERNAL ONLY, project code names).
Trigger "Bulk e-mail addresses" when one paste or file contains at least this many distinct addresses.

Custom rules

Add your own patterns, such as employee IDs, project code names or internal hostnames. Patterns are JavaScript regular expressions.

Sites

Trusted sites are never scanned. High-risk sites are always protected and get the stricter high-risk action.

Pattern syntax. acme.com matches the domain and all subdomains · =app.acme.com this host only · *.acme.com subdomains only · icloud.com/mail* host plus path · re:^https://.+\.acme\.cloud/ regular expression on the full URL. Trusted wins when a site is on both lists.

Reporting

Optionally forward incidents to your security team. Reports contain rule names, counts, the site's hostname, the channel and the user's decision — never the content.

Incidents are POSTed as JSON in batches and retried with back-off. Leave empty to keep everything on this device. Local test: http://localhost:8787/api/dlp/incidents (node tools/dev-server.mjs).
Not included in settings exports.
Include user e-mail in reportsOff by default. Reports are otherwise tied only to an anonymous install ID.
