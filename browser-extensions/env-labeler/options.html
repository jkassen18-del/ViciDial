Rules

Each rule gives a group of sites a colour and a label. Rules are checked from top to bottom and the first enabled rule with a matching pattern wins, so put specific rules above broad ones.

Remote rule sources

Load shared rules from JSON files your team hosts. They are fetched in the background, cached, and checked after company rules and before your personal rules.

Refresh everyMinutes between background refreshes. Sources are also fetched when the browser starts and when you add one.
min
File format 
{
  "name": "Acme environments",
  "rules": [
    {
      "id": "prod", "label": "PRODUCTION", "color": "#DC2626",
      "patterns": ["app.acme.example", "*.prod.acme.example"],
      "ribbon": "top", "faviconTint": true, "titlePrefix": true,
      "border": true, "confirmForms": true
    }
  ]
}

Behaviour

How labels look and behave on every site.

Label environmentsMaster switch. When off, no ribbons, favicons, title prefixes, badges or confirmations are shown.
Allow personal rulesUse the rules you define yourself in addition to company and remote rules.
Confirm destructive clicksOn environments that confirm forms, also ask before clicking buttons labelled Delete, Drop, Destroy, Remove, Truncate, Purge or Deploy.
Toolbar badgeShow the environment tag (PROD, STG, DEV…) on the toolbar icon.

Ribbon

Ribbon sizeThickness of the ribbon in pixels.
Ribbon opacityLower values let more of the page show through.
Show host nameShow the site's host name next to the label on top, bottom and side ribbons.
Allow hiding the ribbonShow a small × on the ribbon that hides it for the rest of the tab session.
Top ribbon pushes content downAdds space above the page so a top ribbon never covers it. Off by default because some sites' fixed headers will not move.
